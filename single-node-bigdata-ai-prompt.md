### Hadoop (Single Node Mode)

- DataNode

- NodeManager
- HistoryServer

### Spark
- Spark Master
- Spark Worker

### Hive
- Hive Metastore (MySQL-backed)
- HiveServer2

## 4. Configuration-Driven Design (CRITICAL RULE)

### Non‑Negotiable Rules
1. **NO hard‑coded versions, ports, memory, or service names**
2. Everything must be read from `cluster_config.yaml`
3. Dockerfiles and docker‑compose must dynamically inject configs
4. XML configs must be generated at container startup

---

## 5. cluster_config.yaml (Single Source of Truth)

```yaml
versions:
  java: 21
  hadoop: 3.4.2
  spark: 4.1.1
  hive: 4.2.0
  mysql: latest
  postgres: latest

ports:
  hadoop:
    namenode_ui: 9870
    resourcemanager_ui: 8088
    historyserver_ui: 19888
  spark:
    master_ui: 8080
  hive:
    hiveserver2: 10000
    hiveserver2_ui: 10002
  monitoring:
    api: 8000
    ui: 3000

databases:
  mysql:
    database: hive_metastore
    user: hive
    password: hivepass
  postgres:
    database: monitoring
    user: monitor
    password: monitorpass
```
